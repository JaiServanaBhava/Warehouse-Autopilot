## 🌟 Executive Overview

Traditional Warehouse Management Systems (WMS) are **passive logbooks**: they show charts of yesterday’s problems and leave floor managers guessing what to do next.

**Warehouse Autopilot** is an **active autonomous command center**. Grounded in real-time orders, carrier deadlines, inventory runways, and physical floor constraints, it:
1. Computes a live **“What Should I Do Now?”** ranked action queue with **1-click execution**.
2. Encodes real-time stock reality into physical **Product QR Intelligence Passports** with printable bin labels and live **Reality Check** verification.
3. Dynamically load-balances workers from idle zones to overloaded picking bottlenecks.
4. Fans out emergency notifications across **Twilio WhatsApp**, **Twilio Email API**, and **Automated Supplier Purchase Orders (PO)** in parallel with zero human delay.
5. Features an embedded **Gemini-Powered Autonomous Copilot** with full live context and persistent multi-view chat memory.

| **1** | 🧠 **“What Should I Do Now?” Autopilot Queue** | Replaces passive analytics with a live prioritized action queue (e.g. *Reallocate 10 units from Order #1082 → #1042*, *Expedite 20 units of KB-303*) with 1-click execution. |
| **2** | 📱 **Product QR Intelligence Passport + Reality Check** | Every SKU has a physical QR passport scannable by any smartphone camera. If inventory changes, the system flags the label as `⚠️ QR OUTDATED` vs. live warehouse truth with 1-click label regeneration. |
| **3** | 🗺️ **Bottleneck Digital Twin & Autonomous Rebalancing** | Visualizes live congestion percentage and order queues across Warehouse Zones (A, B, C, D) with a **`⚡ Rebalance Workers`** button to shift staff dynamically. |
| **4** | ⚡ **Zero-Delay Multi-Channel Incident Fan-Out** | On stockouts or startup/reset, simultaneously dispatches: (1) WhatsApp to Floor Manager, (2) Digest Email to Executives, and (3) Automated PO to Supplier Procurement. |
| **5** | ✦ **Dedicated Autonomous Copilot (Gemini 2.5)** | Full dedicated workspace grounded in live warehouse fact sheets with persistent conversation memory across tabs and view switches. |
| **6** | 🔮 **Decision Engine: "Act vs. Do Nothing" Simulation** | Quantifies financial loss avoided (₹), delayed orders prevented, and explains AI reasoning with transparent confidence scores. |

## 💻 Local Development Setup

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/your-username/warehouse-autopilot.git
cd warehouse-autopilot
pip install -r requirements.txt
```

### 2. Configure Environment (`backend/.env`)
```bash
cp backend/.env.example backend/.env
# Edit backend/.env with your Twilio & Gemini credentials
```

### 3. Start the Application
```bash
python -m uvicorn backend.server:app --reload --port 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
