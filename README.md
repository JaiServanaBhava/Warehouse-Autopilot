## ✨ Feature Showcase

<details open>
<summary><b>🧠 1. Autonomous "What Should I Do Now?" Engine</b></summary>
<br/>

The Decision Engine continuously analyzes your entire warehouse state — inventory runways, order deadlines, zone bottlenecks, customer priority tiers — and outputs a **ranked, executable action queue**.

Every recommendation shows:
- 📌 **Exact action** (e.g. *"Reallocate 10 units KB-303 from Order #1082 → #1042"*)
- 💸 **Financial loss avoided** (e.g. *"Saves ₹34,000 in SLA penalties"*)
- 🎯 **Confidence score** (e.g. *"97% — Act immediately"*)
- 🔍 **Full reasoning** — transparent AI logic, not a black box
- ⚡ **1-click execution** — no copy-paste, no manual steps

```
Priority Queue Example:
1. [CRITICAL 97%] Reallocate KB-303 stock  →  Saves ₹34,000  [APPLY]
2. [HIGH    89%]  Reorder MS-201 (24 units) →  Prevents stockout in 2 days  [APPLY]
3. [MEDIUM  74%]  Rebalance Zone C workers  →  Cuts picking time by 40%  [APPLY]
```

</details>

---

<details open>
<summary><b>📧 2. Automatic 3-Way Notification Fan-Out (Zero Human Action)</b></summary>
<br/>

When a critical event occurs (stockout, SLA breach, QC failure), the system **instantly and simultaneously** dispatches:

```
EVENT: Stockout detected — KB-303 (Mechanical Keyboard) — 0 units
          │
          ├──► 📧 Twilio Email  →  Executive Alert to jaiservanabhava@gmail.com
          │       "URGENT: KB-303 out of stock. 12 customer orders at risk. ₹67,000 exposure."
          │
          ├──► 💬 Twilio WhatsApp  →  Floor Manager on +91 80197 53996
          │       "🚨 CRITICAL: Mechanical Keyboard (KB-303) is at 0 units..."
          │
          └──► 📦 Automated Supplier PO Email  →  Supplier procurement team
                  "PURCHASE ORDER: Please dispatch 30 units of KB-303 urgently."
```

**This happens in under 3 seconds. No human clicks anything.**

Every message is tracked in the live **Notification Outbox** with delivery status, timestamp, and recipient — fully auditable.

</details>

---

<details open>
<summary><b>🤖 3. Gemini 2.5 AI Copilot — Persistent Context-Aware Intelligence</b></summary>
<br/>

A **dedicated full-page AI workspace** powered by Google Gemini 2.5 Flash, grounded in your live warehouse data.

Unlike a generic chatbot, the Copilot **always knows**:
- How many SKUs are out of stock right now
- Which orders are at risk of missing SLA
- Current autopilot score and operational health
- Live zone congestion and worker assignments

**Persistent memory**: Conversation history survives page refreshes, tab switches, and modal openings — stored locally so context is never lost mid-shift.

**Quick action chips** for instant insights:
```
[🚨 What should I do now?]  [📉 Critical Shortages]  [📦 At-Risk Orders]
[🗺️ Rebalance Workers]     [📦 Draft Reorder PO]
```

</details>

---

<details open>
<summary><b>📱 4. QR Intelligence Passport — Every Product Gets a Living Label</b></summary>
<br/>

Every product in the warehouse gets a **scannable QR code passport** that any smartphone camera can read instantly.

The passport shows:
- Live stock levels (physical, reserved, damaged, usable)
- Days until stockout (auto-calculated)
- Reorder recommendation
- Stock status badge (NORMAL / LOW / CRITICAL / OUT OF STOCK)
- Location, supplier, and unit price

**Reality Check Engine**: If inventory changes after the label is printed, the system automatically flags it as `⚠️ QR OUTDATED` with a 1-click regeneration button. Floor staff always have accurate data.

</details>

---

<details open>
<summary><b>🗺️ 5. Live Fulfillment Pipeline — Picking → Packing → QC → Dispatch</b></summary>
<br/>

A complete **end-to-end order execution tracker** with rich live data at each stage:

| Stage | Live Data Shown |
|---|---|
| 🎯 **Picking** | Optimized bin route (e.g. `A07 → B02 → C01`), SKU allocations, assigned picker |
| 📦 **Packing** | Suggested carton spec (`Box M · 2.4 kg · Bubble Wrap`), barcode scan status |
| 🔍 **QC** | Inspection checklist, `[✓ Pass]` / `[✕ Fail & Alert]` with automatic exception creation |
| 🚚 **Dispatch** | Carrier assignment (`Delhivery / BlueDart`), AWB tracking ID, Dock Bay number |

</details>

> A judge can open the Settings panel, enter their own credentials, and test live notifications — **in under 2 minutes, without reading any code.**

## 🚀 Deploy in 5 Minutes (No ngrok. No Docker. No DevOps.)

### Option A — Render (Recommended, Free)

```bash
# 1. Fork this repo on GitHub

# 2. Go to https://dashboard.render.com
#    New → Web Service → Connect your GitHub repo

# 3. Set these build settings:
#    Build Command:  pip install -r requirements.txt
#    Start Command:  uvicorn backend.server:app --host 0.0.0.0 --port $PORT
```

**Add these Environment Variables on Render:**

```env
GEMINI_API_KEY          = AIzaSy...          # From aistudio.google.com/app/apikey
GEMINI_MODEL            = gemini-2.5-flash
TWILIO_ACCOUNT_SID      = your_sid
TWILIO_AUTH_TOKEN       = your_token
TWILIO_EMAIL_FROM       = your@twilio.email
TWILIO_WHATSAPP_FROM    = whatsapp:+1xxxxxxxxxx
TWILIO_WHATSAPP_TO      = whatsapp:+91xxxxxxxxxx
TWILIO_CONTENT_SID      = HXxxxxxxxxxxxx
COMPANY_EMAIL           = you@email.com
SUPPLIER_PO_RECIPIENT   = supplier@email.com
AUTOMATIC_EMAIL_ENABLED = true
AUTOMATIC_WHATSAPP_ENABLED = true
```

**Click Deploy → Get a permanent live URL in ~2 minutes. Done.**

### Option B — Local Development

```bash
git clone https://github.com/your-username/warehouse-autopilot.git
cd warehouse-autopilot
pip install -r requirements.txt

# Add your credentials to backend/.env (see backend/.env.example)

uvicorn backend.server:app --reload --port 8000
# Open http://localhost:8000
```
